Aprende C# jugando

Toca, cambia valores y mira qué pasa. Cada concepto muestra el código y lo que ocurre dentro del programa.

Variables: cajas con nombre

Una variable guarda un dato en memoria. Tiene un tipo, un nombre y un valor.







int = enteros, double = decimales, string = texto entre comillas, bool = true o false. Prueba escribir "hola" en un int y verás el error.








if / else: tomar decisiones


El programa evalúa una condición y sigue solo uno de los dos caminos.









Verdadero
“Eres mayor de edad”


Falso
“Eres menor de edad”






Mueve el control alrededor de 18. Fíjate que >= incluye el 18, pero > no.








for: repetir sin copiar y pegar


Un bucle repite un bloque. Aquí se ejecuta una vez por cada casilla.











Se ejecuta 3 partes: int i = 0 (inicio), i < N (¿sigo?) e i++ (sumar 1 al final de cada vuelta).
